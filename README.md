# استوديو كويز برو — AI Video-Series Creation Studio

استوديو عربي متكامل لصناعة سلاسل الفيديو القصيرة والطويلة (9:16، 16:9، 1:1) انطلاقاً من فكرة أو موضوع واحد، مع المحافظة على جميع أدوات **الاستوديو المتقدم** (شرائح الأسئلة الأربعة، المعاينة المباشرة، بنك الأسئلة، المذيع الذكي، التصدير الفردي والجماعي، والنشر المباشر على يوتيوب).

---

## المسارات الأساسية (Routes)

- **`/` أو `/create`**: الصفحة الرئيسية لإنشاء سلسلة فيديو جديدة (إدخال الموضوع، اختيار الأسلوب، اللغة، الجمهور، مدة الحلقة، عدد الحلقات، المقاس `9:16 | 16:9 | 1:1`، والهوية البصرية الموحدة) مع أمثلة جاهزة وقائمة السلاسل والمشاريع الأخيرة.
- **`/series/:id`**: لوحة إدارة السلسلة ومهام التوليد غير المتزامنة (`queued | generating | reviewing | ready | exporting | failed`)، مع تحرير المشاهد والخط الزمني، التحقق من دقة المعلومات، توليد الأصول البصرية المفقودة، توحيد الهوية البصرية، التصدير الفردي والجماعي، وحزمة النشر الكاملة.
- **`/advanced` و `/advanced/:id`**: محرر **كويز برو** المتقدم بكامل أدواته وشرائحه وتأثيراته وحفظه السحابي والمحلي.

---

## متغيرات البيئة (Environment Variables)

انسخ `.env.example` إلى `.env` وأضف المفاتيح المطلوبة على الخادم فقط (لا تضع مفاتيح الذكاء الاصطناعي في الواجهة):

| المتغير | الغرض |
| --- | --- |
| `GEMINI_API_KEY` / `GEMINI_API_KEYS` | مفتاح Gemini الأساسي على الخادم (أو قائمة مفاتيح للتدوير التلقائي) |
| `GROQ_API_KEY` / `OPENROUTER_API_KEY` / `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` | مزودات احتياطية اختيارية لتوليد النصوص والخطط |
| `TAVUS_API_KEY` | تفعيل المذيع البشري الواقعي (Tavus API v2) اختيارياً |
| `APP_URL` | عنوان النشر الفعلي للتطبيق |
| `VITE_BASE_PATH` | مسار الجذر عند النشر تحت مسار فرعي (الافتراضي `/`) |
| `VITE_API_BASE_URL` | عنوان الخادم الخلفي إذا كان منفصلاً عن الواجهة الثابتة |

## الأوامر الأساسية (Scripts)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير (Express + Vite على المنفذ 3000)
npm run dev

# فحص الأنواع (TypeScript)
npm run lint

# فحص قواعد أمان Firestore
npm run rules:lint

# تشغيل الاختبارات (Vitest)
npm test

# بناء نسخة الإنتاج
npm run build
```

## Firebase & Firestore Rules

قواعد الأمان محددة في `firestore.rules` والمخطط موثق في `firebase-blueprint.json` و`security_spec.md`، وتشمل عزل البيانات لكل مستخدم (`/users/{userId}/...`) مع اشتراط التحقق من البريد الإلكتروني (`email_verified == true`) للمجموعات التالية:
- `brandPresets`
- `series` / `episodes` / `scenes`
- `generationJobs`
- `projects` / `folders` / `questions` / `presets`

لنشر القواعد على مشروع Firebase بعد تعديلها:

```bash
firebase deploy --only firestore:rules
```
